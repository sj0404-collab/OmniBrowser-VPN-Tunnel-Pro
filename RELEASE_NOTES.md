**OmniBrowser VPN Tunnel Pro 4.1.0**

**VPN приложений наконец работает прозрачно — на любом устройстве**
- Раньше в журнале было «устройство не пропускает прозрачный туннель → переключаюсь на режим прокси», а YouTube/Lemur и другие приложения прокси игнорировали. Причина была не в устройстве, а в архитектуре: прозрачный режим пытался «прокрутить» пакеты через ядро (NAT-петля в TUN), что на Android невозможно — ответ сокета нашего приложения не маршрутизируется обратно в VPN.
- Теперь в туннеле работает собственный userspace TCP-стек (как в tun2socks): рукопожатие, окна и масштабирование, подтверждения, повторы, FIN/RST — всё в приложении, поток байт уходит loopback-сокетом в обработчик. Ядро для этого больше не нужно, самопроверка проходит везде.
- Покрыто юнит-тестами: рукопожатие + данные + закрытие, передача 300 КБ при окне 8 КБ, RST на неизвестные сегменты.

**Приложения через серверы Browsec (настоящая смена IP)**
- Если в браузере включено расширение Browsec, TCP приложений из списка VPN идёт через его рабочие бесплатные серверы (предпочитается страна профиля, затем — по пингу), как у браузера с v4.0.7. Если сервер не отвечает — следующий, затем обход DPI.
- Переключатель «🌍 Приложения через серверы Browsec» в карточке «Что сейчас включено»; состояние запоминается.
- В журнале VPN: «приложения идут через сервер Browsec lt…», в строках соединений — «профиль Browsec lt…».

**DNS приложений**
- A-запросы приложений резолвятся через DoH-резолвер сервиса (ответам провайдера больше не доверяем), AAAA/HTTPS — пустой NOERROR, чтобы приложения шли по IPv4 через туннель, а не по IPv6 мимо него.

**Мелочи**
- Запись в TUN ждёт готовности очереди (POLLOUT) вместо потери пакета под нагрузкой; чтение вычитывает пачку пакетов за один poll.
- Удалён мёртвый код старого DNS-цикла; тексты статуса честно описывают режим («через серверы Browsec» / «обход DPI» / «режим прокси»).
- README переписан под реальный продукт (раньше описывал несуществующую «Windows 11 WASM64»).

Подпись — единый ключ (SHA-256 b79d7958…), ставится поверх 4.0.x.
