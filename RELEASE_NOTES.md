**OmniBrowser VPN Tunnel Pro 4.2.6**

**Browsec встроен в APK**
- Расширение Browsec VPN 4.0.0 (официальный пакет из Chrome Web Store, ID `omghfjlpggmjjaagoclmmobgdodcjboh`) лежит внутри приложения и ставится автоматически при первом запуске — и заново после «Очистить данные», без магазина и без сети. В журнале: «встроенное расширение … установлено».
- Если вы сами удалите расширение, приложение не будет его навязывать повторно; если в магазине установлена более новая версия — встроенная её не перекрывает.
- Вход в аккаунт Browsec и выбор страны после очистки данных нужно сделать заново (это данные самого расширения).

Включает исправления 4.2.5: PiP без «чёрной плёнки», кнопки пауза/пуск по фактическому состоянию, отключение прямого пути при подмене DNS провайдером, хеджирование CONNECT для приложений и память «сервер → адресат», сохранение cookies Browsec при очистке.

Подпись — единый ключ, ставится поверх 4.x.
