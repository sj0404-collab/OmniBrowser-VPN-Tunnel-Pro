**OmniBrowser VPN Tunnel Pro 4.2.5**

По журналу 4.2.4 (в том числе строке `[PiP] … "rect":[0,0,192,108], "paused":false`).

**PiP: видео играло, но было закрыто чёрной «плёнкой»**
- Диагностика показала: видео на всё окно, играет, но поверх него — элементы страницы (оверлеи плеера, подложки), а `position:fixed` считался от контейнера плеера с `transform`. Теперь на время PiP видимой остаётся только цепочка «видео → его предки», всё остальное скрывается, а у предков снимаются transform/filter/contain. При выходе из PiP всё возвращается.
- Кнопка «пауза/пуск» действует по фактическому состоянию видео в момент нажатия, а команда повторяется через 0,4 и 1,2 с — чтобы плеер сайта не «откатывал» её. Автовозобновление не вмешивается 5 с после нажатия кнопки.
- Состояние «играет» больше не мигает во время буферизации (значок и авто-вход в PiP стабильны).

**Браузер: YouTube открывался с 6–8 попытки**
- Причина — подмена DNS провайдером: заблокированные сайты «резолвятся» в адрес фильтра (`194.221.250.50`), который принимает TCP мгновенно. В гонке маршрутов прямой путь выигрывал у медленного CONNECT через Browsec, а потом страница ломалась. Теперь, если системный DNS отдаёт известный адрес фильтра или один IP для ≥3 разных сайтов из маршрута, прямой путь для них **не используется вовсе** — только серверы Browsec (в журнале: «DNS провайдера подменяет адрес …»).
- Резервные серверы в гонке — те же измеренные по CONNECT-задержке, что и для приложений (3 лучших), подключаются уже через 1,5 с; общий предел 9,5 с.

**Приложения (Telegram): медленные CONNECT к DC**
- «Хеджирование»: если сервер не ответил на CONNECT за 4 с, параллельно стартует следующий; побеждает первый ответивший.
- Память «сервер → адресат»: для каждого сервера запоминается задержка до конкретного адресата (Telegram DC, Google…), и к нему в следующий раз идёт лучший именно для него сервер; таймаут по адресату больше не портит общую оценку сервера.

**Прочее**
- «Очистить кэш и cookies» больше не сбрасывает вход в Browsec (cookies browsec.com сохраняются).

Подпись — единый ключ, ставится поверх 4.x.
