**OmniBrowser VPN Tunnel Pro 4.0.7**

**Автотуннель через рабочие страны Browsec**
- Если сервер, выбранный в расширении Browsec (например, Греция), не отвечает, сайт теперь идёт через самый быстрый рабочий бесплатный сервер Browsec — Латвия, Литва, Германия… (как в Lemur, с настоящей сменой IP), а не только через обход DPI. Видео YouTube должно играть.
- Список серверов берётся прямо из настроек расширения (его PAC), без доступа к API; есть встроенный запасной список LV/LT/DE. Серверы проверяются по пингу в фоне.
- В «Журнале VPN»: «✅ сайт → автотуннель через Browsec lv…»; в карточке — «автотуннель через Browsec …».
- Профили обхода DPI остаются как были — сайты они открывают.

Подпись — единый ключ (SHA-256 b79d7958…), ставится поверх 4.0.6.
