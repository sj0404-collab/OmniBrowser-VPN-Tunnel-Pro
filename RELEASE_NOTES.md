**OmniBrowser VPN Tunnel Pro 4.2.1**

По журналу 4.2.0: туннель приложений работает (Telegram/AyuGram/Lemur через lt40, lt9, lv86, de58), PiP включается. Остались два момента.

**Видео останавливалось при переключении вкладок**
- Играющая вкладка теперь остаётся на экране **на своём месте**, просто под активной вкладкой (по z-порядку), а не уводится за экран и не скрывается — движок не считает её скрытой ни по видимости, ни по положению.
- Скрипт учёта воспроизведения и перехвата «страница скрыта» дополнительно внедряется после загрузки — для WebView, которые не поддерживают скрипты «до загрузки».
- Вкладки видеосайтов (YouTube, Twitch, RuTube, VK Видео, OK, Дзен, Кинопоиск, SoundCloud, Яндекс Музыка, Vimeo, TikTok, Kick) считаются играющими всегда.

**Туннель приложений: мёртвый сервер задерживал соединения**
- `de73` не отвечал, но на него одновременно шли 3–4 попытки, и каждая ждала таймаут. Теперь сервер, на котором уже висят ≥2 попытки без недавних успехов, пропускается; недавно работавшие серверы идут раньше.
- Порядок выбора: страна профиля приложения → страна, выбранная в расширении Browsec → недавно работавшие → по пингу.
- Сообщение «не отвечает» — не чаще раза в минуту на сервер.

Подпись — единый ключ, ставится поверх 4.x.
